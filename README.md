Capper-Trace

Capper-Trace is a forensic and investigation script for FiveM RP servers.
The script focuses on long term police investigations, realistic evidence handling, and criminal counterplay.
Every action can leave traces behind. Police can investigate them. Criminals can clean them up or avoid leaving them in the first place.

Features
Evidence System
Players can leave behind:

Fingerprints

Blood

DNA

Bullet casings

Cigarettes

Fibers

Vehicle traces

Evidence can be collected and analyzed later.

CCTV System
Cameras around the map can record:


Vehicles


License plates


Player clothing


Time and location


Police can review footage through a simple UI.
Criminals can disable cameras or destroy them.

Phone Tracking
Phones generate signal activity while active.
Police can:


Track signal areas


View tower pings


Follow movement history


Players can use burner phones or destroy devices to avoid tracking.

Crime Scene Investigation
Police can secure scenes and collect evidence using tools.
Examples:


Collect shell casings


Swab blood


Take photos


Store evidence in lockers



Darknet Market
Hidden marketplace for illegal activity.
Players can buy:


Fake IDs


Hacking tools


Illegal equipment



Detective Board
Police investigators can connect:


Suspects


Vehicles


Evidence


Phone numbers


CCTV captures


Useful for building larger investigations over time.
